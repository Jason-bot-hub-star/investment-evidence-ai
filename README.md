# 证据台 · 投资研究工作台 V2.1

> 将投资判断变成可检查的证据链：先澄清口径，再验证支持/反对/未知，最后保留会改变结论的新信息。

## 1. 目标用户与问题
面向形成初步投资判断、但尚未完成证据核验的个人研究者。典型误区是把收入增长当成经营利润增长、混用 GAAP 和调整后 EPS、只搜支持结论的材料。本产品不荐股，不给买卖点，不承诺收益。

本次只做两个清晰范围：
- **真实历史材料案例**：苹果 FY2024 Q4 与 FY2023 Q4 官方业绩公告。
- **虚构情景实验**：示例制造 A，简化利润表模型，检验结论何时随参数变化而翻转。

## 2. 三种运行方式：不能混称
| 方式 | 材料 | 分析方式 | 模型费用 |
|---|---|---|---|
| 历史案例 / 本地规则 | 已核验的苹果官方材料摘录，是真实材料，不是模拟财报 | 预先编码的口径与证据规则；口径切换会改变结论 | 无 |
| 虚构情景 | 所有公司名、数值、报告期均是假设；没有伪造公告链接 | 确定性利润桥计算、阈值翻转 | 无 |
| 真实 AI | 官方摘录快照，或用户明确选择在线复核原文 | 服务端调用用户配置的 OpenAI 兼容模型；支持自由修订和追问 | 按所接服务计费 |

**交付代码时没有取得候选人的模型密钥，未完成实际百炼联调。自动化测试使用模拟模型响应，不是实际模型成功记录。** 本地规则和虚构情景用于可靠展示交互及边界，不能冒充题目要求的真实 AI 主链路。

## 3. 对照题目要求
| 要求 | 实现 | 边界 |
|---|---|---|
| 拆解、澄清并修订投资命题 | 口径选择、澄清后的问题、人工确认；真实AI可编辑命题和子问题 | 本地规则只接受预设命题，不假装理解任意输入 |
| 真实数据和原始材料 | 官方业绩稿摘录、发布日、报告期、原文和财务报表链接；真实模式可在线复核 | 未接入扶摇/iFinD；快照不是实时数据；未解析PDF全表 |
| 支持、反对与无法验证 | 证据方向标签、筛选、引文、来源、解释和局限 | 不为了凑齐类型编造证据；数量不等于结论投票 |
| 处理证据冲突 | 区分GAAP EPS与调整后EPS、两期对比、公式 | 不把EPS等同净利润，不凭收入与EPS完成主营归因 |
| 什么变化会改变结论 | 待补材料、结论变动条件；模拟场景有可计算的翻转阈值 | 模拟阈值是人为模型设定，不是行业标准 |
| 继续比较、追问或保存 | 来源内追问、研究任务、任务状态、打开历史版本、两版本对比、JSON导出 | 仅当前浏览器存储，不是云端账户；追问不是无限长会话记忆 |
| 接口异常和合规 | 鉴权、限流、超时、输出校验、错配引文拦截；可见的异常演练 | 异常演练明确标模拟；实例内限流不是硬性预算上限 |
| Web URL、仓库、说明和视频 | 提供可部署源码、README、测试记录、AI协作记录和录屏脚本 | 候选人仍需部署真实服务、验证外部访问并录制实际演示 |

## 4. 核心产品设计
- **渐进式工作流**：提出命题 → 澄清口径 → 人工确认 → 验证结果 → 后续研究。验证完成自动收起确认区，可展开重看。
- **事实、推论、局限分开**：每条证据保留来源和逐字引文，不能把口径差异藏在总结里。
- **反证优先**：苹果案例让GAAP下降与调整后增长同时可见，避免只搜支持证据。
- **不确定性可操作**：缺失材料进入后续研究，不用一个虚构的“置信度87%”掩盖不足。
- **输入和结果版本绑定**：输入变化会使旧结果失效；已保存的记录保留当时参数，不静默覆盖。
- **保留控制感**：取消、错误恢复、键盘快捷键、关闭弹窗、移动导航、减少动画设置。
- **同花顺参考风格**：根据候选人提供的截图采用浅灰白底、黑色标题、红色主操作和横向导航；颜色为视觉近似，不是官方设计规范。保留“证据台”名称和“非官方产品”标识。
- **金融色彩语义**：增长用红色、下降用绿色；证据支持/反对/未知仍以文字标签和独立配色区分，不把证据方向误作涨跌。

## 5. 数据来源与计算
S24: https://www.apple.com/newsroom/2024/10/apple-reports-fourth-quarter-results/
S23: https://www.apple.com/newsroom/2023/11/apple-reports-fourth-quarter-results/
两期材料来自同一个发行人，不能声称是独立多源交叉验证。

真实案例关键事实：
- FY2024 Q4收入94.9十亿美元，官方披露同比+6%。
- 本期GAAP稀释EPS0.97美元，上期1.46美元；程序计算同比约-33.56%。
- 本期剔除一次性费用后的EPS1.64美元，官方披露同比+12%。
- 2023公告的“同比13%”是2023对2022，不能误用为本次同比。

虚构情景的简化模型：
- 经营利润 = 收入 - 营业成本 - 期间费用。
- 净利润 = 经营利润 + 其他收益 - 税费。
- 主要经营贡献 = 净利润增量>0，经营增量>0，经营增量/净利润增量>50%。
- 比例是带符号增量比，可超过100%；不是概率，不做归一化。
- 其他收益只是非经营项的简化代理，不等于全部为一次性损益。
- 税费为用户给定的独立假设，不自动按税率计算。真实会计需更完整科目与调节。

## 6. 架构
无生产第三方前端依赖、无数据库。仅Node.js内置模块和浏览器原生能力。

```text
index.html / styles.css     页面结构与基础响应式布局
ths-theme.css              同花顺参考红白主题、导航与金融涨跌色
app.js                     交互、状态、任务保存、来源抽屉与比较
engine.js                  纯函数规则引擎，历史口径及假设计算
 data.js                   官方摘录与虚构情景，明确独立标识
api/research.js            鉴权 → 校验 → 材料策略 → 模型调用 → 引文校验
api/health.js              只检查配置是否齐全，不产生模型调用
build.js                   仅复制六个静态文件到public/
tests/                     规则、接口隔离和浏览器测试
```

AI负责理解、拆解、综合解释；程序负责输入校验、计算、引用匹配与状态；人负责命题修订、口径确认和最终判断。引文真实不代表推论一定成立，仍需人工检查。

## 7. Mac最快体验
解压后双击 `index.html`。历史案例和虚构情景不需要安装软件或配置密钥。
真实AI不能只靠双击HTML或GitHub Pages运行，必须部署包含 `/api/research` 的后端。

## 8. GitHub + Vercel部署
1. 在GitHub仓库选择 Add file → Upload files。
2. 上传此目录里的全部文件和 `api`、`tests` 文件夹。不要只上传ZIP，不要套额外的外层文件夹。
3. 在 https://vercel.com/signup 用个人GitHub账号登录。选择 Add New → Project，Import仓库。
4. Framework选择Other，Root Directory选根目录。构建命令和输出目录使用 `vercel.json`。
5. 在Environment Variables填写：

| 名称 | 值 |
|---|---|
| MODEL_API_KEY | 候选人个人模型密钥，不能提交仓库或聊天 |
| MODEL_BASE_URL | 控制台完整OpenAI兼容基础地址，不追加/chat/completions |
| MODEL_NAME | 已开通的模型API标识，非任意展示名 |
| APP_ACCESS_CODE | 候选人自设较长随机访问码，不是API Key |

6. Deploy。修改环境变量后须重新部署。
7. 打开生产网址 → 接入设置 → 选择真实AI → 材料先选“已核验官方摘录” → 输入应用访问码 → 应用设置。
8. “检测部署配置”只验证参数存在；必须真实跑通一次拆解、分析和追问才算联调成功。
9. 用手机移动网络和未登录浏览器确认生产URL可访问；确保评审有源码仓库访问权限。访问码单独提供，不进公开仓库。

开发测试：Node22下运行 `npm test`、`npm run build`。浏览器测试另外需要Playwright和Chromium，执行 `node tests/browser.test.js`；可通过环境变量BROWSER_PATH指定Chromium可执行路径。

## 9. 费用、安全与限制
- 密钥只在服务端环境变量中。页面不保存应用访问码，不导出访问码。
- 输出通过textContent渲染，不把模型文字当HTML运行。
- 原文抓取限定两个白名单URL，不抓任意用户地址。
- 每实例每IP每分钟最多12次请求。无分布式限流，不能代替平台限额；设置费用监控，演示完成后停用专用密钥。
- 网络请求有超时，失败不静默回退为本地规则。
- 前端异常演练不代表实际接口故障测试；服务端隔离测试也不代表真实供应商联调。
- 本机任务最多20项；清理浏览器数据会丢失，建议导出。旧V1任务不自动迁移。
- Vercel地区到模型地区与官网的连通性需候选人验证；不承诺中国大陆任意网络都能访问。
